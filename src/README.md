# src — analysis engine

Deterministic Python that computes every figure (`abc_workbook_adapter.py`, `financial_analysis.py`), runs one client inside a sandbox (`run_client.py`, `client_sandbox.py`), and builds the review packet and Excel pack (`monthly_review.py`, `close_artifacts.py`, `excel_layout.py`). Brief requirement served: numbers come from code, not from the model.
